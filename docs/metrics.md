# 数据画像指标说明

本文逐项说明 `profile()` 提供的 149 个指标 ID（含别名）。每项都给出统计口径、结果能说明什么，以及值得优先查看的场景。报告中的指标可通过中文名称或悬浮提示里的 ID 在本文查找。

## 按场景选指标

| 场景 | 优先查看 | 用来回答的问题 |
| --- | --- | --- |
| 数据刚接入，核对行数和字段 | `row_count`、`column_count`、`profiling_type`、`missing_rate` | 数据到了多少？必填列是否缺值？字段被识别成了什么类型？ |
| 核查主键或排查重复导入 | `is_unique`、`missing_count`、`duplicate_count`、`duplicate_group_row_count` | 键值是否完整且唯一？重复是零星出现，还是同一批记录被反复写入？ |
| 判断数值是否异常 | `min`、`max`、`infinity_count`、`quantiles`、`numeric_histogram` | 是否有越界或无穷值？异常集中在尾部，还是影响了整段分布？ |
| 核查类别覆盖或样本失衡 | `value_counts`、`distinct_count`、`category_imbalance_score` | 哪些类别占多数？哪些类别样本太少？预期类别是否都出现了？ |
| 排查日期解析或采集断档 | `invalid_date_rate`、`time_span`、`datetime_histogram`、`gap_endpoints` | 有多少日期解析失败？记录覆盖哪段时间？缺口具体出现在何时？ |
| 探索列与列的关系 | `pearson_r`、`spearman_rho`、`cramers_v`、`phi_k` | 关联是否线性、单调，或集中在某些类别组合？ |
| 检查文件或图像数据 | `file_size_bytes`、`truncated_image_count`、`image_dimension_counts`、`duplicate_image_hash_count` | 哪些文件异常大或为空？图像是否可完整解码、尺寸是否合规、内容是否疑似重复？ |

跨批次比较时，保持参与画像的列、字段角色和指标参数一致。缺失率、不同值比例等适合与业务约束或历史批次比较。报告中用于提示的阈值只用于筛查，具体异常仍需结合字段用途判断。

## 通用统计口径

- **统计范围**。整表结果的 `columns` 为 `[]`，单列为 `[name]`，列对为 `[a, b]`。同一方法对每个无序列对只返回一次。表缺失、重复组、类型分布和内存统计以参与画像的列为准，`column_count` 始终取原表实际列数。
- **缺失值与无穷值**。`profile()` 将 SQL `NULL` 和浮点 `NaN` 计为缺失。空字符串、空白字符串、零和正负无穷仍属于非缺失观测。无穷值参与数值边界、均值、求和及分位数。数值直方图、数值卡方检验和数值列间相关性使用有限值。
- **分母**。缺失率和特殊值比例按全部观测计算，不同值比例与单例比例按非缺失观测计算。表缺失比例按总行数乘以参与画像的列数计算。各比例返回小数，例如 `0.2` 表示 20%。空输入的计数类比例按下表约定返回 0。
- **结果状态**。`0` 或空列表是已计算的结果。带结果类型的 `null` 表示已计算但无定义，例如均值为 0 时的变异系数。浮点结果还可能返回字符串形式的 `NaN`、`Infinity` 或 `-Infinity`。未请求、不适用或被跳过的指标没有对应记录。

## 整表概况

重复组按所有参与画像的列共同分组。对应位置的 `NULL` 和浮点 `NaN` 在分组时视为相同。空表的缺失计数、缺失比例、重复组数和重复组比例都为 0。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `row_count` 行数 | 原表总行数，每行计一次。 | 核对批次有没有漏入、多入或意外清空。接入、增量同步和对账时先看。 |
| `column_count` 列数 | 原表实际列数，包括未参与画像的列。 | 发现结构变更。换数据源、升级 schema 或比对两批数据时重点看。 |
| `column_type_counts` 列类型分布 | 参与画像的列按画像类型计数，使用显式角色或默认推断。 | 快速确认字段组成。数值、日期突然变成类别时，检查导入和类型配置。 |
| `missing_cell_count` 缺失单元格数 | 将参与画像的各列缺失数相加。 | 估计缺失涉及多少个单元格。安排回填或比较同规模批次时使用。 |
| `missing_cell_rate` 缺失单元格比例 | 缺失单元格数 ÷（总行数 × 参与画像的列数）。分母为 0 时返回 0。 | 比较规模不同的批次整体有多稀疏。比率升高时再查各列缺失率。 |
| `columns_with_missing_count` 含缺失值的列数 | 参与画像的列中，至少有一个缺失值的列数。 | 判断缺失影响多少列。整体缺失比例低而此值较高时，检查缺失是否分散在多个字段。 |
| `all_missing_column_count` 全部缺失的列数 | 非空表中，所有观测都缺失的参与画像列数。 | 识别有字段定义却无数据的列。新增字段上线、映射改动和采集故障时重点看。 |
| `duplicate_group_count` 重复组数 | 按参与画像的列分组后，包含至少两行的组数，每个重复组计一次。 | 判断有多少种重复记录。排查重复导入时与各组行数一起看。 |
| `duplicate_group_rate` 重复组比例 | 重复组数 ÷ 总行数。总行数为 0 时返回 0。 | 用相同分组字段对比各批次的重复组密度。若要算涉及重复的行数，可将各组行数相加。 |
| `duplicate_group_row_count` 各重复组行数 | 返回各重复组的行数列表，按行数降序排列。无重复组时返回空列表。 | 区分许多小组重复和少数组反复写入。估算每组保留一行可删多少行时，对每组行数减 1 后求和。 |

例如 6 行记录里有两个重复组，大小分别为 3 行和 2 行。重复组比例是 `2 ÷ 6`，涉及重复的有 5 行，每组保留一行时可去掉 3 行。

## 单列完整性与类型

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `observation_count` 观测数 | 该列覆盖的总行数，含缺失值。 | 确认统计规模，也是列缺失率和特殊值比例的分母。比较分组或批次时先核对样本量。 |
| `present_count` 非缺失数 | 总观测数减去缺失数。 | 判断可用样本还有多少。建模、聚合或设定最小样本量前重点看。 |
| `missing_count` 缺失数 | 总观测数减去非缺失数。 | 估计需要补录或过滤多少行。主键、金额和其他必填字段出现缺失时优先排查。 |
| `null_count` 空值数 | `missing_count` 的别名，使用同一入口的缺失规则。 | 阅读 AVA 或旧接口的空值监控时按同一口径解读。需要单独计 SQL `NULL` 时，使用原生计划的 `finite` 语义。 |
| `missing_rate` 缺失率 | 缺失数 ÷ 观测数。空表返回 0。 | 衡量一列的数据缺口。选输入字段、排查必填校验和监控批次波动时重点看。 |
| `profiling_type` 画像类型 | 根据数据库类型推断，或使用 `types` 指定的角色。 | 解释一列会启用哪些专项统计。日期字符串、文件路径、普通文本等需要按用途处理时先核对。 |
| `declared_type` 数据库类型 | 计划收到的列声明类型，例如 `DECIMAL(18,2)` 或 `VARCHAR`。 | 检查存储精度和导入类型。金额被存成浮点数、日期被导成字符串时重点看。 |
| `is_groupable` 是否支持分组 | 当前实现对传入的列返回 `true`。 | 了解画像计划给出的分组标记。用复杂列做分组键时，以实际查询能否执行为准。 |
| `is_orderable` 是否支持排序 | 画像识别为数值、字符串、布尔或日期时间时为 `true`，未识别类型时为 `false`。 | 判断画像是否把该列视为可排序标量。选择排序字段、排查复杂类型缺少有序统计时使用。 |

## 不同值与频数

不同值、重复值和单例都围绕非缺失观测计算。以 `[A, A, A, B, NULL]` 为例，非缺失数为 4，不同值数为 2，重复值数为 2，单例数为 1。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `distinct_count` 不同值数 | 非缺失取值去重后的个数。 | 衡量基数。用来找常量列、判断字段像类别还是标识符，以及评估分组规模。 |
| `distinct_rate` 不同值比例 | 不同值数 ÷ 非缺失数。无非缺失值时返回 0。 | 判断列值是否接近逐行唯一。发现标识符、连续变量或异常拆分的类别时与样本量一起看。 |
| `duplicate_count` 重复值数 | 非缺失数减去不同值数。每个取值保留一条后，其余观测计为重复。 | 判断单列按值去重会减少多少行。核查订单号、流水号或候选主键时优先看。 |
| `singleton_count` 仅出现一次的值数 | 恰好出现一次的非缺失值个数。 | 找出低频取值的规模。合并稀有类别、清理拼写变体或分析长尾时可用。 |
| `singleton_rate` 仅出现一次的值比例 | 单例数 ÷ 非缺失数。无非缺失值时返回 0。 | 衡量有多少有效记录对应只出现一次的值。比较不同批次的长尾程度时使用。 |
| `is_unique` 是否唯一 | 至少有一个非缺失值，且非缺失数等于不同值数时为 `true`。 | 初筛候选键。验证主键约束时同时要求 `missing_count = 0`。 |
| `value_counts` 取值频数 | 返回所有非缺失值及其出现次数，频次降序，并列按原生取值升序。 | 查看头部、长尾和异常标签。发现未知类别、编码错误或样本集中时重点看。 |
| `value_counts_by_value` 按值排序的频数 | 与 `value_counts` 覆盖相同的值，按原生取值升序。 | 适合按编码、等级或日期逐个比对。需要观察相邻取值的频次变化时使用。 |
| `top_values` 高频值 | 字符串或布尔列的前 `limit` 个非缺失高频值，默认 3 个。不同值数 > 总行数 × `maxDistinctRatio`（默认 0.5）时跳过。返回 `{entries, truncated}`，其中 `truncated` 表示还有取值未列出。 | 快速识别主流类别或常见占位符。若高基数列缺少该指标，可核对阈值，或按需计算完整频数。 |
| `boolean_mode` 布尔众数 | 出现最频繁的非缺失布尔值。并列时取 `false`，无非缺失值时返回 `null`。 | 查看标记列以哪种状态为主。核对功能开关、正负样本或默认状态时使用。 |
| `boolean_mode_count` 布尔众数频次 | 布尔众数出现的次数。无非缺失值时为 0。 | 衡量主要状态覆盖多少行。除以 `present_count` 可得到主要状态在已知状态中的占比。 |
| `category_imbalance_score` 类别不均衡度 | 按非缺失类别频率计算 `1 − Shannon 熵 ÷ log₂(类别数)`。类别均匀时接近 0，集中于少数类别时趋近 1。只有 0 或 1 个类别时按约定返回 0。 | 筛查样本失衡。划分训练集、校验渠道分布或核对少数类覆盖时，结合 `distinct_count` 和 `value_counts` 看。 |

## 数值

### 位置与总量

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `min` 最小值 | 数值取参与计算的最小值。用于日期列时取最早有效时间。 | 验证业务下界。检查负金额、负时长、过早日期或异常哨兵值时优先看。 |
| `max` 最大值 | 数值取参与计算的最大值。用于日期列时取最晚有效时间。 | 验证业务上界。检查超量、超长延迟、未来日期或溢出时优先看。 |
| `mean` 均值 | 数值总和 ÷ 参与计算的观测数。 | 用一个数概括整体水平。分布偏斜或有极端值时，与中位数、分位数一起看。 |
| `sum` 总和 | 将参与计算的数值相加。 | 对账和核对可加总指标，例如成交额、件数、净增量。数值可正可负时，结合负值数检查抵消。 |
| `median` 中位数 | 排序后的中央值，即 P50。 | 描述典型观测，受极端值影响较小。收入、金额、等待时长等长尾数据优先看。 |
| `range` 极差 | 最大值减最小值。 | 快速确定上下界相距多远。取值范围异常扩大时，与四分位距对照，判断变化是否主要来自尾部。 |

### 波动与分布形状

延展语义下，浮点列含无穷值时，样本标准差、样本方差、变异系数、偏度和超额峰度返回 `NaN`。有限观测不足时，样本波动量可能返回 `null`。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `stddev` 样本标准差 | 样本方差的平方根，与原字段单位相同。 | 衡量观测通常偏离均值多远。对比同单位、规模相近的批次波动时重点看。 |
| `stddev_samp` 样本标准差 | `stddev` 的别名，同样使用样本口径。 | 当报表或模型显式区分样本与总体标准差时使用此 ID，确保口径清楚。 |
| `variance_samp` 样本方差 | 各参与观测与均值的差平方后求和，再除以样本数减 1。单位为原单位的平方。 | 着重反映较大偏差。做方差分析、风险估计或复核标准差时使用。 |
| `cv` 变异系数 | 样本标准差 ÷ 均值。均值为 0 时返回 `null`，均值为负时系数为负。 | 比较均值不同的正值指标的相对波动。均值接近 0 时看标准差或四分位距更容易解释。 |
| `skewness` 偏度 | 样本校正偏度。正值通常表示右尾更长，负值通常表示左尾更长。 | 判断均值是否可能被长尾拉动。金额、时长和流量分布明显不对称时重点看。 |
| `excess_kurtosis` 超额峰度 | 样本校正的超额峰度，以正态分布的 0 为参照。较高值通常表示尾部极端取值更突出。 | 比较尾部风险或排查尖峰异常时，结合高低分位和直方图查看。 |
| `iqr` 四分位距 | P75 减 P25，覆盖中间约 50% 观测的区间宽度。 | 衡量主体数据的波动。极差大而四分位距小时，优先排查两端少量观测。 |
| `mad` 中位绝对偏差 | 对每个观测计算其与中位数的绝对差，再取这些差的中位数。 | 在有离群值时估计典型偏离幅度。做稳健异常检测或比较主体波动时使用。 |

### 特殊值

以下比例均以全部观测为分母，含缺失行。空表返回 0。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `negative_count` 负值数 | 小于 0 的观测数，含负无穷。 | 检查应为非负的库存、耗时或计数。对允许退款和冲销的字段，核对负值是否符合业务。 |
| `negative_rate` 负值比例 | 负值数 ÷ 观测数。 | 比较批次中负值出现的程度。退款、回滚或计算错误集中出现时重点看。 |
| `zero_count` 零值数 | 数值等于 0 的观测数。 | 识别真实零、默认占位或传感器停报。零值与缺失应分别结合字段定义核查。 |
| `zero_rate` 零值比例 | 零值数 ÷ 观测数。 | 衡量零值集中程度。考虑零填充、稀疏建模或发现批量写零时重点看。 |
| `infinity_count` 无穷值数 | 正无穷和负无穷的观测数之和。 | 排查除零、溢出和无效计算。有无穷值时优先检查这列的均值、分位与离散指标是否仍可用。 |
| `infinity_rate` 无穷值比例 | 无穷值数 ÷ 观测数。 | 比较无穷值问题在批次间是否扩大。处理数据清洗或计算链路回归时使用。 |

### 分位数、直方图与均匀性检验

频数保留重复观测。例如一个值出现 20 次，分箱和分位数都按 20 次计。直方图返回 `{counts, edges}`。区间左闭右开，最后一箱包含右端点。开启 `density` 时，`counts` 保存概率密度，每箱密度乘以箱宽才是该箱占比。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `quantiles` 分位数 | 按观测排序，在指定分位位置线性插值，返回分位点到数值的映射。默认 P05、P25、P50、P75、P95。普通整数和浮点使用 DuckDB 原生精确分位，大整数和小数使用带权插值保留精度。 | 同时看典型水平和尾部。延迟、收入等偏斜指标，可用 P50 和 P95 分别观察主体和高端。 |
| `numeric_histogram` 数值直方图 | 将有限数值分箱，返回每箱频数或密度及边界。无有限值时返回空分箱，常量列使用一箱。 | 发现多峰、偏斜、零值集中或长尾。分位数相近但怀疑内部结构变化时重点看。 |
| `chi_squared_statistic` 卡方统计量 | 对各类别或各箱计算 `(实际频数 − 期望频数)² ÷ 期望频数` 后求和，期望是各类别或箱均分。类别、布尔和文本用已出现的取值频数，数值及日期用有效观测自动分箱。无数据时返回 0。 | 衡量偏离均匀分布的程度。抽签、均匀分流等场景有明确均匀预期时重点看，同时核对预期类别是否已出现在数据中。 |
| `chi_squared_p_value` 卡方检验 p 值 | 用卡方统计量和类别数或箱数减 1 的自由度求右尾概率。无数据时按约定返回 0，单类别或单箱时可能为 `NaN`。 | 用来判断观察到的偏差与均匀假设的相容程度。小 p 值要结合样本量、期望频数和频数图解释，先确认输入确有数据且类别或箱数足够。 |

## 日期时间

原生日期和时间戳的边界计算只使用有限时间，带时区的结果转为 UTC。把字符串显式设为 `date` 后，先用 Pandas 解析为 UTC，再按有效时间计算边界、跨度和直方图。无效日期指标统计非缺失原值在 Pandas 中的解析或转换失败情况，因此原生日期也可能因为超出 Pandas 支持的范围而被计入。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `min_timestamp` 最早时间 | 有效时间的最小值。 | 核对历史回溯起点、最早可用档期和错误的默认日期。 |
| `max_timestamp` 最晚时间 | 有效时间的最大值。 | 监控数据新鲜度或查未来日期。检查最近一批是否已到时优先看。 |
| `time_span` 时间跨度 | 最晚时间减最早时间，以纳秒计。无有效时间时返回 `null`。 | 确认总覆盖跨度。跨度满足要求后，可用日期时间直方图检查中间是否都有记录。 |
| `invalid_date_distinct_count` 不同无效日期数 | 解析失败的不同非缺失原值个数。 | 区分单一占位符反复出现和多种格式同时损坏。整理解析规则时重点看。 |
| `invalid_date_count` 无效日期数 | 解析失败的观测行数，同一原值出现多次时每行计一次。 | 衡量日期清洗会影响多少记录。上游日期格式改动或导入后优先核对。 |
| `invalid_date_rate` 无效日期比例 | 无效日期数 ÷ 总观测数，分母含缺失行。空表返回 0。 | 对比批次的解析质量。与 `missing_rate` 一起看，可区分缺值和有值但无法解析。 |
| `datetime_histogram` 日期时间直方图 | 将有效时间按数值时间轴分箱，按原始出现次数计数，输出 UTC 边界。 | 查看时间分布是否集中在某段、是否断档。迁移历史数据、排查补数范围和观察事件集中度时使用。 |

## 文本与 Unicode

长度和字符指标按 Unicode 码点统计，保留空字符串和空白。一个码点可能只是组合字符或表情的一部分。相同字符串出现多次时，按其出现次数计入统计。URL、路径、文件和图像列的文本指标统计的是字段中的字符串。

### 长度、字符与词

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `min_length` 最短长度 | 非缺失字符串的最小字符数，空字符串长度为 0。 | 查空字符串、被截断的编码和过短的输入。定长字段校验时优先看。 |
| `max_length` 最长长度 | 非缺失字符串的最大字符数。 | 检查字段上限、异常长值或超长路径。设置存储、输入框或导出限制时重点看。 |
| `mean_length` 平均长度 | 非缺失字符串的字符数之和 ÷ 非缺失字符串数量。 | 估计平均文本规模。评估摘要长度、展示空间或预处理负荷时使用。 |
| `median_length` 长度中位数 | 各非缺失字符串长度的 P50。 | 观察典型长度。均值明显高于中位数时，检查是否有少量超长记录。 |
| `length_counts` 长度频数 | 对每种整数长度计数，按长度升序返回。 | 精确定位不合规的长度。校验邮编、序列号、定长编码和混合格式时优先看。 |
| `length_histogram` 长度直方图 | 将字符串长度按区间分箱，每个长度的权重是对应的行数。 | 查看长度的整体形状。自由文本可能混有几种模板或大批截断记录时重点看。 |
| `character_count` 字符总数 | 所有非缺失字符串的字符数之和。 | 估计文本处理量。比较体量相近的批次，或预估字符级处理开销时使用。 |
| `distinct_character_count` 不同字符数 | 至少出现过一次的不同 Unicode 码点数。 | 了解字符集有多杂。仅允许数字、ASCII 或限定符号的字段突然出现更多不同字符时重点看。 |
| `character_counts` 字符频数 | 每个字符出现的总次数，包含同一字符串内的重复。 | 定位意外空格、标点、替换字符或分隔符。乱码排查、提取规则设计时使用。 |
| `word_counts` 词频 | 文本转小写，按空白切分，再去掉两端的 ASCII 标点和空白。按 `stopWords` 过滤，重复词逐次计数，纯标点片段可能得到空词项。 | 查看重复词、模板词和常见主题。适合已用空格分隔的文本，连续中文会作为一个词项计数。 |

### Unicode 分类

类别描述字符的用途，例如字母、数字或标点。区块是 Unicode 中命名的码点范围。脚本描述字符所属的书写系统，例如 Latin、Han，标点等共享字符可以归入 Common。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `unicode_category_distinct_count` 字符类别数 | 出现过的 Unicode 通用类别数量。 | 快速检查定格式字段是否混入额外类别。只允许数字或字母时重点看。 |
| `unicode_category_frequencies` 字符类别频数 | 按通用类别汇总字符出现次数。 | 判断数字、标点、空格等占多大比例。清洗结构化文本时优先看。 |
| `unicode_category_character_counts` 各字符类别的字符频数 | 逐个类别列出字符及其频数。 | 在异常类别内定位具体符号。需要编写允许列表或替换规则时使用。 |
| `unicode_block_distinct_count` 字符区块数 | 出现过的 Unicode 区块数量。 | 发现字符范围变宽。预期单一区块的编码或短标签变化时重点看。 |
| `unicode_block_frequencies` 字符区块频数 | 按 Unicode 区块汇总字符出现次数。 | 识别全角符号、扩展字符或特殊区块有多常见。排查显示和归一化问题时使用。 |
| `unicode_block_character_counts` 各字符区块的字符频数 | 逐个区块列出字符及其频数。 | 定位来自异常区块的具体字符。字体排查、半角全角转换和兼容性核对时使用。 |
| `unicode_script_distinct_count` 书写系统数 | 出现过的 Unicode 脚本标签数量，含 Common 等共享标签。 | 快速判断字符的书写系统是否混杂。仅预期单一文字的标签或编码出现异体字符时重点看。 |
| `unicode_script_frequencies` 书写系统频数 | 按 Unicode 脚本汇总字符出现次数。 | 查看主要书写系统和少量混入字符。评估多语种文本或格式一致性时使用。 |
| `unicode_script_character_counts` 各书写系统的字符频数 | 逐个脚本列出字符及其频数。 | 找出来自意外书写系统的字符。发现外形相近的跨脚本字母或异常输入时使用。 |

## 列对关联

前三种数值相关系数有正负方向，范围为 −1 到 1。偏差校正的 Cramér V 和 Phi-K 用 0 到 1 表示关联强度。比较不同方法或批次时，要留意有效配对行数、稀有类别和分箱方式。强关联可用于提出假设，因果判断还需要业务机制或研究设计的证据。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `pearson_r` 皮尔逊相关系数 | 对两列都有有限数值的行计算线性相关。 | 判断两列是否近似沿直线同向或反向变化。检查共线性、重复度量或线性关系时优先看。 |
| `spearman_rho` 斯皮尔曼相关系数 | 对有效数值配对分别取秩，再计算秩的 Pearson 相关，并列值共享平均秩。 | 识别随另一列持续变大或变小的关系。怀疑关系单调、曲线形状明显或有极端值时使用。 |
| `kendall_tau` 肯德尔秩相关系数 | 基于有效数值配对，比较任意两行在两列中的相对次序，用 Kendall τ 衡量同序和逆序的程度，并考虑并列。 | 比较两种评分或排名是否一致。关注相对顺序、离散评分出现并列时使用。 |
| `cramers_v` 克拉默 V 系数 | 从两列类别的有效配对建立列联表，计算经偏差校正的 Cramér V。每列需有 2 至 100 个不同非缺失值。 | 衡量类别搭配是否有关联。对比渠道与结果、地区与品类时，结合列联表定位主要组合。 |
| `phi_k` Phi-K 相关系数 | 对已识别类型使用 Phi-K 的列联表和连续变量分箱方法。数值列至少有 2 个不同有限值，其他列需有 2 至 100 个不同非缺失值。 | 筛查混合类型和非线性关联。怀疑有分段、U 形或类别与连续值关联时使用。 |
| `auto_correlation` 自动关联度 | 数值对用 Spearman，类别对用 Cramér V。混合对先把数值列分成 10 个等宽箱，再用 Cramér V。每列至少有 2 个不同有效值，类别列最多 100 个。 | 快速浏览常见数值和类别组合。解释结果时按实际使用的方法判断方向和强度，时序的滞后相关见 `acf`。 |

## 网址

网址列需要显式指定 `url` 角色。指标使用 Python 的 `urlsplit` 拆分字符串，按原始观测行计数，缺少某个部件时可出现空字符串项。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `url_scheme_counts` 网址协议频数 | 按 URL 的 scheme 部件统计出现次数，例如 `http`、`https`。 | 核对协议迁移、发现缺少协议或出现非预期协议的记录。 |
| `url_netloc_counts` 网址主机频数 | 按完整网络位置部件计数，可包含主机、端口和用户信息。 | 看访问集中在哪些来源。域名迁移、代理配置变动或出现意外来源时重点看。 |
| `url_path_counts` 网址路径频数 | 按 URL 的路径部件计数。 | 找常见页面或接口。排查路由变更、错误页面或埋点路径时使用。 |
| `url_query_counts` 网址查询参数频数 | 按 `?` 后、片段前的整段查询字符串计数，保留参数原有顺序和编码。 | 查常见查询组合、重复参数模式或高基数来源。核对跟踪参数和缓存分裂时使用。 |
| `url_fragment_counts` 网址片段频数 | 按 `#` 后的片段字符串计数。 | 查看锚点或使用片段路由的页面分布。单页应用路由或文档锚点改动时关注。 |

## 路径

`path`、`file`、`image` 角色都可统计路径部件，按执行机器的 `os.path` 规则拆分。同一路径出现多次时，部件频数累计对应的行数。部件为空时也可以形成一个不同值。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `path_common_prefix` 路径公共前缀 | 将路径作为字符串，取最长公共字符前缀。无公共前缀时返回 `No common prefix`，前缀可以停在目录名中间。 | 快速查看路径是否具有共同开头。迁移或统一目录时，结合父路径频数确认实际目录范围。 |
| `path_stem_counts` 文件主名频数 | 按去掉最后一个扩展名后的完整路径计数，目录部分仍在。 | 比较同一目录下不同扩展名的同名产物。检查导出版本或配套文件缺失时使用。 |
| `path_suffix_counts` 文件后缀频数 | 按最后一个扩展名计数，扩展名包含前导点。 | 查看文件格式构成。验收入库格式、排查无后缀文件或混合扩展名时优先看。 |
| `path_basename_counts` 文件名频数 | 按路径末段计数，保留扩展名。 | 找不同目录下重复出现的文件名。汇总目录、排查命名冲突或覆盖风险时使用。 |
| `path_parent_counts` 父路径频数 | 按路径的目录部分计数。 | 识别主要目录和异常目录。核对批次落盘位置或来源目录时使用。 |
| `path_drive_counts` 驱动器频数 | 用宿主的 `splitdrive` 取驱动器部分后计数。采用 POSIX 路径规则时，该部分通常为空。 | 核对 Windows 路径是否分布到预期卷或网络共享。迁移跨卷数据时重点看。 |
| `path_stem_distinct_count` 不同文件主名数 | 去掉最后一个扩展名后，不同完整路径的数量。 | 估计逻辑文件基名规模。需要对比同名多格式文件的覆盖率时使用。 |
| `path_suffix_distinct_count` 不同文件后缀数 | 不同最后扩展名的数量。 | 判断格式是否单一。接入的格式种类超出预期时，再用后缀频数定位。 |
| `path_basename_distinct_count` 不同文件名数 | 不同路径末段的数量，文件名包含扩展名。 | 判断命名的多样性。同一批应产生独立文件名时，结合总量和频数检查重复。 |
| `path_parent_distinct_count` 不同父路径数 | 不同目录部分的数量。 | 衡量文件分散到多少个目录。预期只有一个落盘位置或做目录迁移时使用。 |
| `path_drive_distinct_count` 不同驱动器数 | 宿主拆出的不同驱动器部分的数量，空部件也作为一个取值。 | 核对路径是否跨卷。由单卷迁至多卷、合并共享盘目录时重点看。 |

## 文件

文件和图像的文件元数据由执行画像的机器读取，按字段中记录的路径值统计。时间频数使用宿主本地时区和秒精度。无法读取文件元数据时，画像请求会报错。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `file_size_bytes` 文件大小（字节） | 返回每个不同路径的 `{path, bytes, count}`，其中 `count` 是路径出现次数。 | 精确定位空文件和异常大文件。核对上传、导出和容量时优先看。 |
| `file_size_histogram` 文件大小直方图 | 按字节大小分箱，同一路径的大小按出现次数计权。 | 看数据中的文件大小是否有长尾或多种典型体量。设定传输和读取容量时使用。 |
| `file_modified_time_counts` 文件修改时间频数 | 按文件内容修改时间 `mtime` 计数，同一路径按出现次数累计。 | 判断文件最近何时写入或更新。核对交付批次、排查旧产物时重点看。 |
| `file_access_time_counts` 文件访问时间频数 | 按系统记录的最近访问时间 `atime` 计数，同一路径按出现次数累计。 | 查看文件最近被触达的线索。使用前确认文件系统如何更新访问时间。 |
| `file_metadata_change_time_counts` 文件元数据变更时间频数 | 按宿主返回的 `ctime` 计数，同一路径按出现次数累计。在 Unix 类系统中，它是文件状态变更时间。 | 追查权限、所有权或文件状态变更。跨平台使用时先确认宿主对 `ctime` 的定义。 |

## 图像

图像指标需要显式指定 `image` 角色。尺寸和面积只统计成功打开并加载的图像，宽高为像素数，面积为宽 × 高。成功图像的尺寸、哈希和 EXIF 频数按路径出现次数计权。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `truncated_image_count` 截断图像数 | Pillow 能打开但加载失败的图像观测数。打开阶段就失败的文件不会计入。 | 识别文件头可读、图像数据不完整的记录。上传中断、下载损坏和格式转换失败时重点看。 |
| `image_dimension_counts` 图像尺寸频数 | 按 `[宽, 高]` 组合计数。 | 找主流分辨率和不符合规格的尺寸。素材验收和训练预处理前优先看。 |
| `min_image_width` 最小图像宽度 | 成功图像的最小宽度。 | 查横向分辨率下限。要求图像达到最小宽度时重点看。 |
| `max_image_width` 最大图像宽度 | 成功图像的最大宽度。 | 查是否有超宽素材。校验上传或缩放上限时重点看。 |
| `mean_image_width` 平均图像宽度 | 以出现次数为权重，算成功图像的平均宽度。 | 估计整体横向尺寸，比较来源或批次的分辨率时使用。 |
| `median_image_width` 图像宽度中位数 | 按出现次数计权的宽度 P50。 | 查看典型宽度。有全景等极宽图像时，优先用它确定常见规格。 |
| `min_image_height` 最小图像高度 | 成功图像的最小高度。 | 检查纵向分辨率下限。发现条带图或小图混入时重点看。 |
| `max_image_height` 最大图像高度 | 成功图像的最大高度。 | 发现超长图。图片预览、裁切或垂直尺寸有限制时重点看。 |
| `mean_image_height` 平均图像高度 | 以出现次数为权重，算成功图像的平均高度。 | 估计整体纵向尺寸。对比不同来源的缩放和裁切策略时使用。 |
| `median_image_height` 图像高度中位数 | 按出现次数计权的高度 P50。 | 查看典型高度。少量长图抬高均值时，用于判断多数图像的规格。 |
| `min_image_area` 最小图像面积 | 成功图像中，宽 × 高的最小值。 | 找总像素过低的图像。设置识别、审核或素材验收下限时使用。 |
| `max_image_area` 最大图像面积 | 成功图像中，宽 × 高的最大值。 | 估计极端情况下的解码或裁切工作量。存在超高分辨率素材时优先看。 |
| `mean_image_area` 平均图像面积 | 先求各图像的宽 × 高，再按出现次数算平均。 | 估计通常每条记录涉及多少像素。准备批量缩放、预处理或计算预算时使用。 |
| `median_image_area` 图像面积中位数 | 各图像面积按出现次数计权后的 P50。 | 查看典型图像的像素规模。少量超大图影响平均面积时优先看。 |
| `exif_tag_counts` 图像元数据标签频数 | 对成功图像含有的 EXIF 标签计数。 | 核对拍摄时间、方向等标签的覆盖。依赖元数据做筛选或旋转纠正时重点看。 |
| `exif_value_counts` 图像元数据取值频数 | 按标签分组，统计每种 EXIF 取值的文本表示及频数。 | 查看具体设备、方向或其他元数据值。数据来源核对、EXIF 一致性检查时使用。 |
| `duplicate_image_hash_count` 重复图像哈希数 | 对成功图像计算感知哈希（pHash），按哈希精确匹配分组。重复数为有哈希的观测数减去不同哈希数。 | 筛查内容相同或相似的图像。同一路径重复出现也会贡献计数，素材去重或检查训练集重复时可进一步验证。 |

## 顺序与时间序列

画像按 `orderBy` 提供的列升序排列。未提供排序列时，使用 `timeIndex` 升序。若排序键相同，可指定次级键让顺序可复现。单调性适用于索引之外的数值列，以下时序专项指标需要 `timeIndex`，索引值不得缺失。设置了显式 `timeseries` 角色后，专项指标只计算这些序列。否则使用索引之外的数值列。

### 单调性

单调性按画像顺序比较非缺失值，缺失值会被跳过。只剩零个或一个有效值时，四项判断均为 `true`。检查完整的业务序列时，同时核对 `present_count` 和 `missing_count`。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `is_nondecreasing` 是否单调不减 | 每个有效值都大于或等于前一个有效值。 | 检查允许持平的累计量。累计订单、里程或计数器回退时重点看。 |
| `is_nonincreasing` 是否单调不增 | 每个有效值都小于或等于前一个有效值。 | 检查允许持平的递减量。余额消耗、剩余时长或配额意外上升时使用。 |
| `is_strictly_increasing` 是否严格递增 | 每个有效值都严格大于前一个有效值。 | 验证递增序号或版本。需要每次增长并发现重复值时优先看。 |
| `is_strictly_decreasing` 是否严格递减 | 每个有效值都严格小于前一个有效值。 | 验证必须逐步下降的序列。要查停滞或反向增长时重点看。 |

### 时间索引（整表）

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `time_series_count` 时间序列数 | 统计显式 `timeseries` 列数。未指定时，统计索引之外的数值列数。 | 核对预计参与分析的序列是否都选中了。读多变量时序报告时先看。 |
| `time_index_observation_count` 时间索引观测数 | 时序输入中带时间索引的总行数。重复的索引值仍逐行计数。 | 确认输入样本量。对照预期采样次数时，再核查索引有没有重复。 |
| `time_index_start` 时间索引起点 | 时间索引的最小值。空表返回 `null`。 | 核查分析窗口或采集是否从预期时点开始。 |
| `time_index_end` 时间索引终点 | 时间索引的最大值。空表返回 `null`。 | 核查序列最新观测和覆盖终点。监控停止更新或延迟入库时重点看。 |
| `mean_time_index_step` 平均时间索引步长 | 按画像顺序计算相邻索引的差，取绝对值后求均值。相同索引贡献 0，少于两行返回 `null`。 | 估计平均采样间隔。检查采样频率变化时，结合缺口和重复索引查看。 |

### 平稳性与季节性

平稳性检验、季节性检测和自相关均按有序有效观测处理，先去掉序列缺失值。季节周期和滞后阶数以观测步数表示。采样节奏规律时，可用采样间隔把步数换算成时间。采样不规则时，先核对索引步长和缺口。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `adf_p_value` 平稳性检验 p 值 | 用 statsmodels 的增广 Dickey–Fuller（ADF）检验单位根，返回 p 值。数据不足或为常数等导致检验失败时返回 `null`。 | 判断序列是否有足够证据拒绝单位根假设。拟合时序模型、考虑差分或去趋势时优先看。 |
| `is_stationary` 是否平稳 | ADF 的 p 值小于 `significance`，且未检出季节性时为 `true`。ADF 无定义时返回 `null`。 | 快速查看序列是否通过当前画像的平稳性判断。模型有平稳要求时，再结合 p 值、季节周期和走势复核。 |
| `is_seasonal` 是否有季节性 | 有效序列的 FFT 频谱中至少检出一个通过峰值阈值和谐波过滤的峰时为 `true`。 | 筛查周期性重复。流量、交易和传感器数据怀疑有固定节奏时与周期列表一起看。 |
| `seasonal_periods` 季节性周期 | 将保留下来的各个正频率取倒数，得到每个周期的观测步数。无检出周期时为空列表。 | 估计重复间隔。例如等间隔小时数据中的约 24 步对应约一天。选择季节窗口时重点看。 |

### 缺口

对每个序列，取相邻两条非缺失观测的时间索引之差。先求所有正间隔的均值，某个间隔严格大于该均值的 2 倍时，记为一个缺口。较长的间隔也参与均值计算，会抬高阈值。短序列或普遍稀疏的序列也应对照约定采样频率。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `gap_count` 时间缺口数 | 符合缺口阈值的相邻间隔个数。 | 判断有多少次异常断档。监控采集、上传或传感器可用性时优先看。 |
| `gap_endpoints` 时间缺口端点 | 返回每个缺口两侧的时间索引 `[前一观测, 后一观测]`。无缺口时为空列表。 | 定位断档窗口，以便与发布、故障和补数记录对照。 |
| `min_gap` 最短时间缺口 | 所有已识别缺口中最短的间隔。无缺口时返回 0。 | 了解被识别的断档最短有多长。排查短时中断时结合端点使用。 |
| `max_gap` 最长时间缺口 | 所有已识别缺口中最长的间隔。无缺口时返回 0。 | 定位影响最久的停报或漏数。安排补数和追查故障时重点看。 |
| `mean_gap` 平均时间缺口 | 所有已识别缺口的间隔均值。无缺口时返回 0。 | 概括断档通常持续多久。比较同采样频率的批次时使用。 |
| `stddev_gap_samp` 时间缺口样本标准差 | 已识别缺口长度的样本标准差。零个或一个缺口时按约定返回 0。 | 判断断档长度是否相近。区分持续时间接近的重复中断与长短差异大的故障时使用。 |

### 自相关

`acf` 和 `pacf` 返回由滞后阶数、系数和置信区间组成的列表。置信水平为 `1 − significance`。有效序列长度为 `n` 时，最大滞后为 `lags` 与 `max(0, floor(n/2) − 1)` 的较小值。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `acf` 自相关（ACF） | 对有效序列计算其与自身错开不同步数后的相关，使用 FFT。 | 查看序列的历史影响和重复节奏。排查模型残差是否仍有时间依赖、核对周期时重点看。 |
| `pacf` 偏自相关（PACF） | 使用 Yule–Walker 最大似然法，计算控制较短滞后影响后的各阶相关。 | 判断哪些滞后仍有直接关联。选择自回归模型的候选阶数时，与 ACF 一起看。 |

## 内存

以内存中的 Pandas 表示为准，单位为字节。需要至少一列参与画像。`memoryDeep: true` 可进一步统计 Pandas 对象中字符串等对象的内存。评估磁盘文件大小或 DuckDB 查询峰值内存时，应使用对应的实测数据。

| 指标 | 统计口径 | 作用与重点关注场景 |
| --- | --- | --- |
| `table_memory_bytes` 表内存（字节） | 参与画像的列在 Pandas 中的内存占用之和，含一次表索引开销。 | 估计把数据加载到 Pandas 的体量。做容量预算、怀疑批次过大时优先看。 |
| `mean_row_memory_bytes` 平均每行内存（字节） | 表内存字节数 ÷ 总行数。空表返回 0。 | 粗估相同结构的数据增量。行数变化较大时，用它区分记录变重和记录变多。 |
| `column_memory_bytes` 列内存（字节） | 每个 Pandas Series 的内存占用，包含该 Series 的索引开销。 | 查找占内存较多的字段。按列相加会重复计入索引，估计整表总量时直接看表内存。 |

## 调用与配置

`profile()` 默认使用完整的 `ALL_METRICS`，返回适用于当前数据和配置的结果。`metrics` 可接收 ID 子集，空数组表示不计算，重复 ID 以最后一项为准。`createProfilingPlan()` 生成单条原生 SQL，默认选择 15 项。AVA 可显式选用只读 `BASIC_METRICS`，包含 `row_count`、`null_count`、`distinct_count`、`top_values`、`min`、`max`、`mean`。[AVA 接入说明](./ava.md)

原生计划默认 `semantics: 'finite'`，缺失只计 SQL `NULL`，位置和离散等数值聚合只用有限值。特殊值计数仍可检测无穷值。`semantics: 'extended'` 使用与 `profile()` 相同的基础统计语义，将浮点 `NaN` 计为缺失，并按指标保留无穷值。`decodeWithDiagnostics(row)` 同时返回 `results` 和 `skipped`，跳过原因可为 `unsupported_type` 或 `cardinality_limit`，诊断复用同一次查询的结果。

| 配置 | 默认值与统计影响 |
| --- | --- |
| `types` | 按列名指定 `numeric`、`categorical`、`text`、`boolean`、`date`、`url`、`path`、`file`、`image`、`timeseries`。角色须与数据库类型兼容，例如字符串可指定 `date`。未指定时，按声明类型推断数值、类别、布尔、日期时间或未识别类型。低基数的数值列仍为数值。 |
| `timeIndex`、`orderBy` | `timeIndex` 指定数值或日期时间索引。`orderBy` 是优先使用的升序列名列表。未配置顺序时跳过单调性指标，时序专项需要 `timeIndex`。 |
| `top_values` 的 `limit`、`maxDistinctRatio` | 分别默认 3 和 0.5，放在该指标的配置对象中。`limit` 是非负安全整数，比例阈值取 `[0, 1]`。 |
| `quantiles` | 默认 `[0.05, 0.25, 0.5, 0.75, 0.95]`。使用非空数组，每个点取 `[0, 1]`。 |
| `bins`、`maxBins`、`density` | 默认 `50`、`250`、`false`。固定箱数受不同值数量和上限约束。`bins: 0` 启用 Freedman–Diaconis / Sturges 自动分箱。数值和日期卡方检验单独自动分箱。浮点舍入导致的重复数值箱边界会合并。箱数配置和原生数值自动卡方分箱上限为 100000。 |
| `stopWords` | 默认 `[]`，词频过滤时忽略大小写。 |
| `lags`、`significance` | 默认最大滞后 100、显著性水平 0.05。滞后配置为 0 至 100000 的整数，显著性水平取 `(0, 1)`。 |
| `autolag`、`maxlag` | ADF 默认按 `AIC` 选阶，由 statsmodels 决定最大滞后。`autolag` 还接受 `BIC`、`t-stat` 或 `null`。`maxlag` 可设为 0 至 100000 的整数，可用范围还受样本量限制。 |
| `memoryDeep` | 默认 `false`，传给 Pandas 的内存测量。 |
| `fileRoot` | 可选目录。相对路径基于该目录解析，实际路径及符号链接目标须位于目录内，并指向普通文件。 |
| `python` | 默认使用 `python3`，支持指定其他解释器。专项依赖见包中的 `python-requirements.txt`，要求 Python 3.10+。 |

频数明细的格式为 `[{value, count}]`。分位数为分位点到值的对象，直方图为 `{counts, edges}`。结构中的值仍按 `MetricValue` 标记类型，整数和小数用字符串保留精度，浮点聚合可能有末位误差。数值中位数和离散度沿用 DuckDB 原生精度。

基础聚合、频数、重复组、数值直方图、普通数值分位和 Pearson 等由 DuckDB 计算。需要 Python 的指标按需通过临时 Parquet 传送不同值及频数，或导出必要的原始列。内存统计使用全部参与画像的列。精确去重、完整频数、跨列关联、时序、图像哈希及 EXIF 可能消耗较多内存、计算或 I/O，可用 `metrics` 只选需要的指标。Python worker 会复用依赖，空闲 30 秒后退出，每次请求重新读取数据。专项计算失败会使整个请求失败并清理临时文件。
