# AVA 数据画像

AVA 数据画像是一个面向 DuckDB SQL 的数据画像项目，灵感来自 [fg-data-profiling](https://github.com/Data-Centric-AI-Community/fg-data-profiling)。从缺失值、取值频数到分布和重复组，统计结果都可以用 SQL 查询和复用。

> [!NOTE]
> 项目目前处于设计阶段。下面展示拟议的 AVA SQL 调用方式。

## 使用示例

假设 DuckDB 中有一张 `orders` 表，其中 `amount` 和 `quantity` 是数值列，`channel` 是文本列，`created_at` 是时间戳列。

```sql
SELECT * FROM ava_profile('orders');
```

这次调用覆盖适用于订单表的核心指标。表级统计给出行列数、各类型列数、重复组数及其比例，各列统计缺失值、取值频数和不同值数。数值列再算范围、基础聚合、分位数和直方图，`channel` 计算文本长度，`created_at` 计算时间范围。两列数值之间还会计算 Pearson 和 Spearman 相关性。

## 核心指标

**重要性**按各组统计对 AVA 通用画像的价值评估。五星是核心指标，四星常用于进一步排查，三星视场景使用，两星用于专项分析，一星适用于少数领域。

| 范围 | 指标 | 重要性 | 计算口径 |
| --- | --- | :---: | --- |
| 表规模 | 行数、列数 | ⭐⭐⭐⭐⭐ | 统计输入表或视图的行数和列数。 |
| 列类型 | 各类型的列数 | ⭐⭐⭐⭐⭐ | 按画像类型汇总列数。 |
| 重复组 | 重复组数及比例 | ⭐⭐⭐⭐⭐ | 按参与画像的字段值分组，统计至少包含两行的组数。比例以总行数为分母。 |
| 列缺失 | 观测数、缺失数、缺失率、非缺失数 | ⭐⭐⭐⭐⭐ | 逐列统计观测总数和缺失数。两者相减得到非缺失数。缺失率以观测总数为分母。 |
| 取值频数 | 取值频数、按值排序的频数 | ⭐⭐⭐⭐⭐ | 统计每个非缺失值出现的次数。取值可比较时，按值排序可查看两端取值及其频次。 |
| 不同值 | 不同值数及比例 | ⭐⭐⭐⭐⭐ | 精确统计非缺失的不同值数，并除以非缺失观测数得到比例。 |
| 数值位置与范围 | 最小值、最大值、均值、总和、极差 | ⭐⭐⭐⭐⭐ | 对数值做基础聚合。极差等于最大值减去最小值。 |
| 分位数 | 分位数、中位数 | ⭐⭐⭐⭐⭐ | 计算指定分位点的值，例如 P5、P25、P50、P75 和 P95。P50 即中位数。 |
| 数值分布 | 数值直方图 | ⭐⭐⭐⭐⭐ | 对有限数值分箱，保留边界和各箱频数。 |
| 日期时间范围 | 最早时间、最晚时间、时间跨度 | ⭐⭐⭐⭐⭐ | 在有效日期时间中找到最早和最晚值，再计算两者的间隔。 |
| 字符串长度 | 最短、最长、平均和中位字符串长度 | ⭐⭐⭐⭐⭐ | 统计字符长度，再按各长度出现的次数计算最小值、最大值、均值和中位数。 |
| 线性和秩相关 | Pearson 相关、Spearman 秩相关 | ⭐⭐⭐⭐⭐ | 分别衡量两个数值列的线性关联和秩关联。 |
